## A Federated Learning Approach for Speech Anti-Spoofing and Deepfake Detection  
* Employed a wav2vec 2.0 frontend for feature extraction and a lightweight Multi-Scale Dilation Attention Network
(MDAN) backend for multi-scale feature processing and classification.
* Achieved 2.92% EER (equal error rate) and 0.2672 t-DCF (tandem detection cost function) on ASVspoof 2021
Logical Access and 2.99% EER on DeepFake partition, outperforming several centralized baselines.
